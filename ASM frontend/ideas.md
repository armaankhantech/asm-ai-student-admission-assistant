# ASM AI — Reference Recreation Specification

The ground-truth visual reference is the authorized [ASM CSIT website](https://www.csit.edu.in/). This project must reproduce its institutional presentation as faithfully as practical while limiting application routing to `/` and `/enquiry`.

## Chosen direction

**Reference-faithful ASM CSIT website + ASM AI.** The official ASM CSIT logo, official website banners, student/campus-related website imagery, Montserrat/Roboto typography, navy/blue/orange treatment, large hero/banner composition, overlay navigation, compact cards, and dark institutional footer are the governing visual system. The new green **Enquire Now** action and original ASM AI overlay are additive features only.

## Non-negotiable rules

- Never use the Campus Ledger name, style, logo, prospectus framing, generated compass, invented marketing slogan, or generated campus illustration.
- Use official/authorized ASM CSIT assets in the header, hero, major sections, assistant header, and footer where available.
- Preserve recognizable ASM CSIT navigation labels and visual rhythm; keep those destinations as homepage anchors except for `/enquiry`.
- Let ASM AI look like an additional professional college-assistant layer, not a rebrand of the college website.
- Keep the frontend-only boundary, no-fake-AI rule, two-route limit, and service abstractions unchanged.

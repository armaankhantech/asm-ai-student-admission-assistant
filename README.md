# 🌟 WHAT IS ASM AI?

**ASM AI** is an AI-powered student and admission assistant created for the ASM College of Commerce, Science & Information Technology (CSIT).

The system combines:

- 🤖 AI-powered student assistance
- 📚 Verified college knowledge
- 🔎 Retrieval-Augmented Generation (RAG)
- 📝 Admission enquiry collection
- 🗄️ PostgreSQL persistence
- ⚡ Database-triggered automation
- 🔄 n8n workflow orchestration
- 🧠 AI-powered enquiry analysis
- 📧 Automated admissions-team notification
- ✉️ Automated student confirmation
- 📱 Direct WhatsApp connection to admissions

The goal of V1 is simple:

> **Help students get information faster while reducing repetitive manual work around admission enquiries.**
